# Lampac Source Grid v0.6 — яркие цветные бейджи на тёмных плитках

**Установка (GitHub Pages):**
https://ipvideocom-star.github.io/lampa-plugins/source-grid/lampac-source-grid-v0.6.js

**Исходник:**
https://github.com/ipvideocom-star/lampa-plugins/blob/main/source-grid/lampac-source-grid-v0.6.js

## Исправление после v0.5

- Возвращены **обычные тёмные плитки**, как в v0.4.
- **Только метки разрешения** яркие: 2160p/4K — красный (`#FF1744`), 1080p/FHD — жёлтый (`#FFEB00`), 720p/HD — зелёный (`#08E65A`), 480p/SD — серый.
- Зелёные/серые точки результата Lampac сохранены без изменений.
- Заголовок «Выбор источника», три колонки, стрелки пульта и клавиша Enter работают по прежней логике.
- Сверху оставлено только `Результат: N/M · Разрешение — из названия или справочно`, без очевидных пояснений «зелёный — есть» и «серый — нет».
- `ghost=true` по-прежнему делает недоступный источник приглушённым.

## Обновление в гостевой Chrome

1. Lampa → Настройки → Расширения: удалить предыдущий тестовый URL `v0.5.js`.
2. Добавить **только** URL `v0.6.js`.
3. Нажать F5 и дождаться уведомления «Source Grid v0.6 загружен».
4. Открыть фильм → Онлайн → «Выбор источника» и проверить внешний вид.

**Откат:** удалить v0.6 и при необходимости вернуть v0.4. Не добавлять две версии Source Grid одновременно.

Примечание: метки разрешения по-прежнему извлекаются из названий источников или справочной таблицы и не гарантируют реальное качество потока.

Рабочие файлы Lampac NG, `init.conf`, Samsung-setup JS, серверные источники, прокси и авторизация не изменялись.

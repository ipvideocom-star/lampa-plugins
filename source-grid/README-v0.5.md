# Lampac Source Grid v0.5 — яркие плитки «светофор»

Отдельная тестовая версия клиентского плагина Lampa для Samsung Tizen, Android TV и Chrome.

**Прямая ссылка на JS (GitHub Pages):**
https://ipvideocom-star.github.io/lampa-plugins/source-grid/lampac-source-grid-v0.5.js

**Исходник на GitHub:**
https://github.com/ipvideocom-star/lampa-plugins/blob/main/source-grid/lampac-source-grid-v0.5.js

## Отличия от v0.4

- 2160p / 4K: ярко-красный \`#FF1744\` — вся плитка и отдельный бейдж
- 1080p / FHD: ярко-жёлтый \`#FFEB00\`
- 720p / HD: ярко-зелёный \`#08E65A\`
- 480p / SD: нейтрально-серый \`#A5ACB7\`
- Если Lampac сообщает \`ghost=true\`, плитка остаётся серой (качество не означает доступность).
- Фокус стрелок/пульта дополнительно обведён контрастным белым контуром.
- Над плитками оставлено: \`Результат: 19/22 · Разрешение — из названия или справочно\` (числа динамические).
- Удалены пояснения \`Зелёный — есть\` и \`Серый — нет\`.
- Выбор источника и навигация стрелками/Enter сохранены из v0.4.

## Тестирование

1. В гостевой Lampa → **Настройки → Расширения** удалить URL \`v0.4.js\`.
2. Добавить только URL \`v0.5.js\`. Старые версии одновременно не держать.
3. Обновить Lampa и проверить сообщение «Source Grid v0.5 загружен».
4. Фильм → Онлайн → Выбор источника: проверить яркие цвета, серые плитки, стрелки и Enter.
5. Проверить на Samsung Tizen и Android TV отдельно после успешного Chrome-теста.

## Оговорки

Метки 2160p/1080p/720p берутся из названия источника или резервной справочной таблицы, **не являются измерением реально доступного разрешения видео**.
Зелёная точка означает наличие результата поиска Lampac, а не гарантию запуска потока на конкретном устройстве.

Никаких изменений в продакшн \`C:\lampacNG-next\`, \`init.conf\`, Samsung setup JS, TelegramAuth, прокси или уже настроенных онлайн-источниках.

## Откат

Удалить URL v0.5 из расширений тестового клиента; вернуть ранее работающий URL v0.4.

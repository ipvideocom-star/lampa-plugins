# Lampac Source Grid v0.4 — цветные метки качества

Клиентский плагин Lampa (Samsung Tizen / Android TV / Web), не меняет Lampac NG и серверные настройки.

## URL для установки

https://ipvideocom-star.github.io/lampa-plugins/source-grid/lampac-source-grid-v0.4.js

Исходный код:
https://github.com/ipvideocom-star/lampa-plugins/blob/main/source-grid/lampac-source-grid-v0.4.js

## Изменения относительно v0.3

- Если в названии источника явно написано разрешение, теперь показано именно `2160p`, `1080p`, `720p`, `480p` — не обобщённые `4K/FHD/HD/SD`.
- Цвет бейджа: 2160p/4K — фиолетовый фон и золотистая окантовка; 1080p/FHD — синий; 720p/HD — зелёный; 480p/SD — серый.
- Если разрешения нет в названии, справочные метки из таблицы и `window.LampacSourceGridConfig.qualityHints` продолжают работать. Дополнительно допустимы значения `2160p`, `1080p`, `720p`, `480p` в пользовательской таблице.
- Сами плитки остаются тёмными. Отдельные зелёные / серые **индикаторы результата Lampac** не меняются.
- Навигация стрелками и Enter, выбор источника, заголовок «Выбор источника» и счётчик результатов остались от v0.3.
- Уведомление о загрузке: «Source Grid v0.4 загружен».

## Как испытать без риска для других устройств

1. В гостевом Chrome открой Lampa → Настройки → Расширения.
2. Удали URL `v0.3.js` и добавь только URL `v0.4.js`.
3. Перезагрузи Lampa (F5) и дождись уведомления о загрузке v0.4.
4. Открой фильм → «Онлайн» → «Выбор источника».
5. Проверь цвета меток, переключение источников мышью и стрелками/Enter.
6. После подтверждения на Chrome отдельно проверяй Samsung и Android TV.

**Не устанавливать v0.3 и v0.4 одновременно.** При проблемах удалить только v0.4 и вернуть известную рабочую v0.3.

## Ограничения и проверки

Разрешение, написанное в названии, **не является независимым измерением потока**. Резервные метки — справочные, основанные на ранее согласованной таблице. Зелёная точка говорит о результате поиска, но не гарантирует воспроизведение на данном телевизоре.

Проверены V8-синтаксис и 10 тестовых комбинаций разбора источников/разрешений. Реальные Samsung Tizen и Android TV для v0.4 ещё не тестировались.

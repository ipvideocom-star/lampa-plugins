# Lampac Source Grid v0.1 — тестовый клиентский плагин Lampa

## Адрес для тестового подключения (GitHub Pages)

`https://ipvideocom-star.github.io/lampa-plugins/source-grid/lampac-source-grid-v0.1.js`

Адрес сконструирован для обычного GitHub Pages, обслуживающего ветку main и корень репозитория. GitHub-файл опубликован, но доступность Pages снаружи из этой среды не подтверждена.

Резервная ссылка на исходник: https://github.com/ipvideocom-star/lampa-plugins/blob/main/source-grid/lampac-source-grid-v0.1.js

Проверка: откройте адрес в обычном Chrome. Если вместо текста JavaScript получаете 404, проверьте страницу [Settings → Pages](https://github.com/ipvideocom-star/lampa-plugins/settings/pages) для репозитория и только после исправления добавляйте URL в расширения Lampa.

## Назначение

Заменяет визуальное оформление штатного окна **выбора источников Lampac NG** плитками в три колонки (2 на узких экранах, 1 на мобильных). Использует штатные элементы Lampa и переданные Lampac объекты (`title`, `source`, `ghost`, `selected`), поэтому выбор источника сохраняет штатный обработчик.

Подходит как тестовая заготовка для **Samsung Tizen, Android TV и Lampa Web**. На физических устройствах пока не проверено.

## Важные ограничения

* Зелёный кружок — у Lampac для выбранного фильма/сериала есть результат (`ghost=false`). Это **не проверка доступности файла, звука, кодека, скорости или запуска на телевизоре**.
* Серый кружок — `ghost=true` (возможно, поиск ещё идёт или результат отсутствует). Условие полностью берётся из ответа Lampac.
* Метки HD/FHD/4K берутся из названия, а при отсутствии — из справочной таблицы на основе предоставленного скриншота. **Они не доказывают реальное качество конкретного потока.** Справочную таблицу можно исключить или переопределить до загрузки.
* Плагин не добавляет и не удаляет онлайн-источники, не меняет `init.conf`, не создаёт прокси и не трогает доступ по UID.
* Для совместимости не подключать одновременно с другими плагинами, которые заменяют `Lampa.Select.show` / `Lampa.Controller.add` или вид окна выбора источников (в т.ч. Source Sort), до отдельной проверки.

`lampac-source-grid-v0.1.js` — единственный исполняемый файл.

## Безопасный план внедрения

1. Сохранить JS вне рабочего каталога Lampac, например в **отдельном тестовом репозитории на GitHub Pages**.
2. Открыть один клиент Lampa в Chrome, добавить HTTPS-адрес файла в **Настройки → Расширения** и обновить страницу.
3. Открыть фильм → «Онлайн» → штатную кнопку выбора источника. Сравнить цвета/подписи с исходными данными Lampac; проверить стрелки **← → ↑ ↓**, **OK**, **Назад**.
4. Проверить переход к Filmix и Kinobase, закрытие списка и возвращение в карточку; проверить обычные меню Lampa и работу других плагинов.
5. Только после этого выборочно включить на одном Samsung или Android TV. Существующий механизм выборочной выдачи и клиентские расширения не изменять до согласования.
6. При возникновении проблем удалить тестовый URL из списка расширений конкретного клиента и перезапустить Lampa. Продакшн-файлы Lampac не трогались.

## Кастомизация качества

До подгрузки плагина можно определить:

```js
window.LampacSourceGridConfig = {
    qualityHints: {
        filmix: 'HD',
        kinobase: '4K',
        mirage: ''
    }
};
```

Это только **визуальные подписи**. Чтобы показывать достоверную характеристику качества для каждого фильма, нужен другой источник данных / отдельная логика проверки, чего v0.1 не делает.

## Обоснование реализации

По исходнику `lampac-nextgen/lampac/Online/plugin.js` список сортировки строится с `title`, `source`, `selected`, `ghost`. Исходник `yumata/lampa-source/src/interaction/select.js` показывает штатную логику кнопок и обработчика `onSelect`. Плагин не переписывает колбэк выбранного источника, а только оформляет совпадающий список и исправляет навигацию по сетке для пульта.

## Проверено

* Статическая проверка JavaScript: `node --check` — успешно.
* Смоук-тест браузерного имитатора с массивом источников: строятся 4 плитки, метки качества, `ghost`-плитка, навигация вправо/вниз, колбэк выбора и очистка при закрытии — успешно.
* **Не проверено**: Samsung Tizen, Android TV, встраивание в официальную Lampa при реальном воспроизведении, совместимость с внешним «Ліхтариком».

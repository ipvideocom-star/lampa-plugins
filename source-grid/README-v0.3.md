# Lampac Source Grid v0.3 — TV-friendly source picker

Экспериментальное клиентское расширение Lampa для Samsung Tizen, Android TV и браузера.
**Не изменяет Lampac NG, серверные исходники, init.conf, прокси, UID и другие плагины.**

## Плагин

GitHub Pages: https://ipvideocom-star.github.io/lampa-plugins/source-grid/lampac-source-grid-v0.3.js

Исходник: https://github.com/ipvideocom-star/lampa-plugins/blob/main/source-grid/lampac-source-grid-v0.3.js

## Отличия от v0.2

- «Сортировать» → «Выбор источника» только для определённого окна выбора источников Lampac.
- Крупнее плитки, отступы и бейджи HD/FHD/4K.
- Над списком отображается число источников, для которых Lampac сообщил о результате.
- Механизм выбора и переходы стрелками/Enter из v0.2 сохранены без изменений.
- При загрузке показывается уведомление «Source Grid v0.3 загружен».

## Безопасный тест

1. В *гостевой* Chrome откройте Lampa → Настройки → Расширения.
2. Удалите тестовый URL v0.2, затем добавьте адрес v0.3. **Не устанавливайте обе версии одновременно.**
3. Обновите Lampa (F5). Дождитесь «Source Grid v0.3 загружен».
4. Откройте фильм → Онлайн → выбор источников: должны быть плитки в три колонки, заголовок «Выбор источника».
5. Проверьте стрелки клавиатуры и Enter. Затем можно отдельно испытывать на одном Samsung и одном Android TV.

## Ограничения

Зелёная точка означает, что Lampac сообщил о результате поиска. Это **не проверка воспроизводимости потока**, аудиодорожек, кодеков и доступности на устройстве. Серые плитки соответствуют `ghost=true`; поиск по некоторым источникам может продолжаться. HD/4K — справочная маркировка, а не достоверное качество каждого файла.

В v0.3 не вносятся изменения в загрузку плагинов на отдельных устройствах. Выборочное развёртывание — отдельный этап после реальных проверок.

## Обратимость

Если возникнут проблемы, удалите только v0.3 из списка расширений тестовой Lampa и вернитесь к проверенной v0.2. Исходник v0.2 сохранён без изменений.

## Техническая проверка

Node.js `--check`: успешно.
Локальный smoke-тест: инициализация, фильтрация нужного меню, заголовок, статистика, создание плиток, `ghost`, стрелка вправо, очистка после закрытия, сохранение остальных меню — успешно.
Натуральные Samsung Tizen и Android TV пока **не проверены**.
